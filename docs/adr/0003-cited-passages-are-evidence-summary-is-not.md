# Cited passages are evidence; the summary is not

Conversations stay open after their Sources expire instead of becoming read-only. The Mentor's evidence is the Chunks of the Conversation's remaining Sources plus the passages already saved in its Citations, which are verbatim Source text. The rolling summary and message history are passed as context only and must never be used as evidence, because they are the model's own paraphrase and would let it drift beyond what the Sources say.

Notes and the One Page are paraphrase too, so they are never cited. The Mentor may still state what they conclude, because questions like "what do I train on leg day?" or "what is the book's main argument?" are answered by a section's outline or the whole book, which no single Chunk holds. When it does, the answer says so in words, naming a Note's section and pages, so the reader can tell the Mentor's interpretation from the book's text and check the pages.

## Considered Options

- Read-only once every Source has expired: simple, but ends Conversations that still hold real evidence.
- Answer from the summary and history after Expiry: keeps the Conversation alive, but grounds answers on model-written text.
- Cite Notes like passages: one mechanism for both, but presents paraphrase in the same place as the book's own words.
- Notes only steer retrieval: keeps answers verbatim-grounded, but the Mentor can't state what only a section's outline shows.
